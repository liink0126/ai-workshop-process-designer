# AI 워크숍 프로세스 디자이너

조직의 문제나 목표를 입력하면 Liink 컨설팅의 전문 지식을 바탕으로 AI가 맞춤형 워크숍 프로세스를 설계해주는 도구입니다.

View your app in AI Studio: https://ai.studio/apps/drive/108gw1WGnNvmjwDjjF1xjfKgU7TPKW9oM

## 🎯 주요 기능

### 🤖 AI 기반 워크숍 설계
- **Google Gemini 2.5 Pro**를 활용한 고품질 맞춤형 워크숍 계획 자동 생성
- Liink 컨설팅의 전문 지식이 반영된 구조화된 워크숍 프로세스
- 워크숍 유형별 최적화된 설계 (팀 빌딩/소통, 아이디어/전략, 비전/목표 수립 등)
- 복잡한 워크숍 설계에 최적화된 Pro 모델로 더욱 정교한 계획 생성

### 📊 3P 분석 시스템
- **Purpose (목적)**: 워크숍의 'Why' - 왜 필요한지, 어떤 변화를 만들고 싶은지
- **Product (결과물)**: 워크숍의 'What' - 끝났을 때 손에 쥐게 될 구체적인 결과물
- **Participant (참여자)**: 워크숍의 'Who' - 누가 참여하는지, 그들의 특성과 상황
- AI가 3P 정보를 분석하여 최적의 워크숍 프로세스 제안

### 💬 AI 진단 채팅
- 대화형 인터페이스로 워크숍 핵심 요소를 자연스럽게 정의
- 간단한 질문에 답하면 자동으로 3P 정보 추출 및 정리
- 초보자도 쉽게 워크숍 설계 시작 가능

### 📈 난이도 분석
- 워크숍 성공 가능성 평가
- 퍼실리테이터 역량 요구사항 분석
- 워크숍 복잡도 및 실행 난이도 시각화

### 🔄 실시간 편집 기능
- **드래그 앤 드롭**: 워크숍 단계 순서를 직관적으로 변경
- **AI 대체 제안**: 각 단계에 대한 대안 제안 요청
- **타임라인 뷰**: 워크숍 전체 흐름을 시간 순서로 시각화
- **리스트 뷰**: 상세 정보를 포함한 단계별 목록 보기

### 💾 워크숍 관리
- **히스토리 저장**: Firebase를 통한 워크숍 계획 자동 저장
- **워크숍 복사**: 기존 워크숍을 복사하여 수정 및 재사용
- **템플릿 기능**: 자주 사용하는 워크숍을 템플릿으로 저장하여 빠르게 재사용
- **템플릿 사용**: 저장된 템플릿을 클릭 한 번으로 불러와서 수정

### 🔍 검색 및 필터링
- **실시간 검색**: 제목, 목적, 결과물, 유형 등으로 워크숍 검색
- **유형별 필터**: 워크숍 유형(팀 빌딩, 아이디어, 비전 등)으로 필터링
- **날짜 범위 필터**: 오늘, 이번 주, 이번 달, 최근 3개월 등으로 필터링
- **필터 조합**: 검색어와 필터를 조합하여 원하는 워크숍 빠르게 찾기

### 🔗 워크숍 공유
- **URL 공유**: 워크숍을 URL로 공유하여 다른 사람과 함께 확인
- **원클릭 복사**: 공유 링크를 클립보드에 한 번에 복사
- **공유 링크 접속**: 공유된 링크로 접속하면 워크숍 자동 로드

### 📱 사용자 지원
- **사용자 가이드**: 4단계 가이드로 워크숍 설계 방법 안내
- **FAQ**: 자주 묻는 질문과 답변 제공
- **모바일 반응형**: 스마트폰, 태블릿, 데스크톱 모든 기기에서 최적화된 경험

### ⚡ 사용자 경험 개선
- **로딩 상태**: 진행률 표시와 동적 메시지로 명확한 피드백
- **에러 처리**: 사용자 친화적인 에러 메시지와 복구 안내
- **입력 검증**: 실시간 입력 검증 및 피드백

## 📖 사용 흐름

### 1. 워크숍 설계 시작
- **AI 진단 채팅**: "AI 컨설턴트와 대화 시작하기" 버튼 클릭 → 간단한 질문에 답변 → 자동으로 3P 정보 추출
- **직접 입력**: 폼에 직접 Purpose, Product, Participant 정보 입력

### 2. 워크숍 생성
- 워크숍 유형 선택 (팀 빌딩/소통, 아이디어/전략, 비전/목표 수립 등)
- 참여자 수, 소요 시간, 준비물 등 추가 정보 입력
- "워크숍 설계하기" 버튼 클릭 → AI가 맞춤형 워크숍 프로세스 생성

### 3. 워크숍 편집 및 최적화
- 드래그 앤 드롭으로 단계 순서 변경
- 각 단계에 대한 AI 대체 제안 요청
- 타임라인 뷰와 리스트 뷰 전환하여 전체 흐름 확인
- 난이도 분석 확인하여 워크숍 복잡도 파악

### 4. 워크숍 저장 및 관리
- "워크숍 저장하기" 버튼으로 Firebase에 저장
- "My History" 페이지에서 저장된 워크숍 조회
- 검색 및 필터링으로 원하는 워크숍 빠르게 찾기
- 워크숍 복사, 템플릿 저장, 공유 기능 활용

### 5. 템플릿 활용
- 자주 사용하는 워크숍을 템플릿으로 저장
- 템플릿을 클릭 한 번으로 불러와서 수정하여 새로운 워크숍 생성

## 🚀 Vercel에 배포하기

### 배포 전 준비사항

1. **GitHub에 코드 푸시**
   - 프로젝트를 GitHub 저장소에 푸시합니다
   - Vercel은 GitHub 저장소와 연동하여 자동 배포합니다

2. **환경 변수 준비**
   - 다음 환경 변수들을 Vercel 대시보드에 설정해야 합니다:
     - `VITE_GEMINI_API_KEY`: Google Gemini API 키
     - `VITE_FIREBASE_API_KEY`: Firebase API 키
     - `VITE_FIREBASE_AUTH_DOMAIN`: Firebase 인증 도메인
     - `VITE_FIREBASE_PROJECT_ID`: Firebase 프로젝트 ID
     - `VITE_FIREBASE_STORAGE_BUCKET`: Firebase 스토리지 버킷
     - `VITE_FIREBASE_MESSAGING_SENDER_ID`: Firebase 메시징 발신자 ID
     - `VITE_FIREBASE_APP_ID`: Firebase 앱 ID
     - `VITE_FIREBASE_MEASUREMENT_ID`: Firebase 측정 ID (선택사항)

### 배포 방법

#### 방법 1: Vercel CLI 사용 (권장)

1. **Vercel CLI 설치**
   ```bash
   npm install -g vercel
   ```

2. **Vercel 로그인**
   ```bash
   vercel login
   ```

3. **프로젝트 배포**
   ```bash
   vercel
   ```
   
   - 첫 배포 시 프로젝트 설정을 묻습니다
   - 프레임워크는 자동으로 Vite로 감지됩니다
   - 환경 변수는 대시보드에서 설정하거나 CLI에서 입력할 수 있습니다

4. **프로덕션 배포**
   ```bash
   vercel --prod
   ```

#### 방법 2: Vercel 웹 대시보드 사용

1. **Vercel 가입 및 로그인**
   - [vercel.com](https://vercel.com)에 접속하여 계정 생성

2. **새 프로젝트 추가**
   - 대시보드에서 "Add New" > "Project" 클릭
   - GitHub 저장소 선택 또는 Import

3. **프로젝트 설정**
   - Framework Preset: **Vite** (자동 감지됨)
   - Root Directory: `.` (프로젝트 루트)
   - Build Command: `npm run build` (자동 설정됨)
   - Output Directory: `dist` (자동 설정됨)
   - Install Command: `npm install` (자동 설정됨)

4. **환경 변수 설정**
   - 프로젝트 설정 > Environment Variables에서 다음 변수들을 추가:
     ```
     VITE_GEMINI_API_KEY=your_gemini_api_key
     VITE_FIREBASE_API_KEY=your_firebase_api_key
     VITE_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
     VITE_FIREBASE_PROJECT_ID=your_project_id
     VITE_FIREBASE_STORAGE_BUCKET=your_project.appspot.com
     VITE_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
     VITE_FIREBASE_APP_ID=your_app_id
     VITE_FIREBASE_MEASUREMENT_ID=your_measurement_id
     ```
   - 각 환경(Production, Preview, Development)에 대해 설정 가능

5. **배포 실행**
   - "Deploy" 버튼 클릭
   - 배포가 완료되면 자동으로 URL이 생성됩니다

### 배포 후 확인사항

1. **빌드 로그 확인**
   - Vercel 대시보드의 Deployments 탭에서 빌드 로그 확인
   - 에러가 있다면 로그를 확인하여 수정

2. **환경 변수 확인**
   - 배포된 사이트에서 Firebase 초기화 오류가 발생하지 않는지 확인
   - 브라우저 콘솔에서 에러 메시지 확인

3. **자동 배포 설정**
   - GitHub에 푸시할 때마다 자동으로 배포됩니다
   - Pull Request 생성 시 Preview 배포가 자동으로 생성됩니다

### 커스텀 도메인 설정

1. Vercel 대시보드 > 프로젝트 > Settings > Domains
2. 원하는 도메인 추가
3. DNS 설정 안내에 따라 도메인 제공업체에서 설정

### 문제 해결

**빌드 실패 시:**
- `package.json`의 빌드 스크립트 확인
- Node.js 버전 확인 (Vercel은 자동으로 최신 LTS 버전 사용)
- 환경 변수가 올바르게 설정되었는지 확인

**환경 변수 오류 시:**
- Vercel 대시보드에서 환경 변수가 올바르게 설정되었는지 확인
- 변수 이름이 `VITE_`로 시작하는지 확인
- 재배포 후 브라우저 캐시를 지우고 다시 시도

**Firebase 오류 시:**
- Firebase Console에서 호스팅 도메인을 허용 목록에 추가
- Firebase 보안 규칙이 올바르게 설정되었는지 확인

## 🚀 로컬에서 실행하기

### 필수 요구사항
- **Node.js 18 이상**
- **npm** 또는 **yarn**

### 빠른 시작

1. **의존성 설치**
   ```bash
   npm install
   ```

2. **환경 변수 설정**
   
   프로젝트 루트에 `.env` 파일을 생성하세요:
   ```bash
   cp .env.example .env
   ```
   
   `.env` 파일을 열어서 다음 값들을 설정하세요:
   ```env
   # 필수: Gemini API Key
   # Google AI Studio에서 발급: https://aistudio.google.com/app/apikey
   VITE_GEMINI_API_KEY=your_gemini_api_key_here
   
   # 필수: Firebase 설정
   # Firebase Console > 프로젝트 설정 > 일반 > 앱에서 확인
   VITE_FIREBASE_API_KEY=your_firebase_api_key
   VITE_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
   VITE_FIREBASE_PROJECT_ID=your_project_id
   VITE_FIREBASE_STORAGE_BUCKET=your_project.appspot.com
   VITE_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
   VITE_FIREBASE_APP_ID=your_app_id
   VITE_FIREBASE_MEASUREMENT_ID=your_measurement_id
   ```

3. **개발 서버 실행**
   ```bash
   npm run dev
   ```
   
   브라우저에서 `http://localhost:3000`으로 접속하세요.

4. **프로덕션 빌드**
   ```bash
   npm run build
   npm run preview
   ```

### 환경 변수 가져오기

#### Gemini API Key
1. [Google AI Studio](https://aistudio.google.com/app/apikey)에 접속
2. "Create API Key" 클릭
3. 생성된 API 키를 `.env` 파일의 `VITE_GEMINI_API_KEY`에 입력

#### Firebase 설정
1. [Firebase Console](https://console.firebase.google.com/)에 접속
2. 프로젝트 선택 (또는 새 프로젝트 생성)
3. 프로젝트 설정 > 일반 탭으로 이동
4. "내 앱" 섹션에서 웹 앱 추가 (또는 기존 앱 선택)
5. Firebase 구성 객체의 값들을 `.env` 파일에 입력

### 문제 해결

**Firebase 초기화 오류가 발생하는 경우:**
- `.env` 파일이 프로젝트 루트에 있는지 확인
- 환경 변수 이름이 `VITE_`로 시작하는지 확인
- 개발 서버를 재시작 (`Ctrl+C` 후 `npm run dev`)

**Gemini API 오류가 발생하는 경우:**
- API 키가 올바르게 설정되었는지 확인
- API 키에 충분한 할당량이 있는지 확인
- Google AI Studio에서 API 키 상태 확인
